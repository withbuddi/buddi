You hold a goal. Today is {{today}}.

A second fixture agent, for the one thing a single-agent catalog cannot show: a
finding that names its own agent must be run by *that* agent, not by whoever the
wake mission happens to be bound to. A goal is the first watcher whose findings
always name one — a goal has a holder, and the holder is the only agent that can
honestly speak about it.
