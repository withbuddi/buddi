# Buddi Blob Mascot Reference Kit

This package defines how Buddi Blob should be designed, commissioned, varied, reviewed, and delivered.

## Contents

1. `buddi-blob-character-bible.md` - canonical identity and visual rules.
2. `buddi-blob-commissioning-brief.md` - brief to send to a designer or illustrator.
3. `buddi-blob-variation-system.md` - how to create agent, emotion, action, and status variants.
4. `buddi-blob-prompt-templates.md` - reusable prompts for image-generation workflows.
5. `buddi-blob-delivery-qa-checklist.md` - approval, export, naming, and quality checks.

## Recommended workflow

1. Start with the Character Bible.
2. Complete the Commissioning Brief for a new asset or asset family.
3. Use the Variation System to decide what may change.
4. Give the artist or generator the relevant prompt template.
5. Review the result with the Delivery and QA Checklist.
6. Record approved assets with a version number and role name.

## Current status

Buddi Blob is at **v0.1 concept stage**. The concept sheet (`concept-sheet-v0.1.png`) is a direction, not yet a final production master. The first production milestone should be a clean canonical turnaround and expression sheet.
